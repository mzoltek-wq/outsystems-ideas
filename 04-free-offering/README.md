# Free offering redesign and Mentor Access concept

Reduce signup friction with prompt-first Mentor access, playgrounds, sample agents, usage credits, MCP access, and clearer free-to-paid conversion.

Proposed ideas. Daily-credit exploration and the one-week prototype are alternatives, not a single approved offer. The page simulates signup and OML delivery; it does not provision access.

Next decision: Choose the intended free model, limits, retention/export behavior, and upgrade triggers before presenting any terms as committed.
