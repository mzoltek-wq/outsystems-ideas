## 3) Differentiation framework: “From Prompt → Process”  
A clear mental model we repeat publicly:

### The Enterprise Agent Execution Stack
**Layer 1 — LLM / reasoning**
- Claude / GPT / Gemini  
- prompt, context, tool invocation  
> We don’t replace this.

**Layer 2 — Orchestration (OutSystems focus)**
- multi-step workflows  
- long-running state  
- conditional branching  
- multi-agent coordination  
- human-in-the-loop injection  
> This is where enterprise agents fail.

**Layer 3 — Integration**
- SAP / legacy .NET / on-prem DBs  
- vendor platforms  
- internal APIs + external APIs  
> Copilots don’t solve this.

**Layer 4 — Governance + controls**
- RBAC, permissions propagation  
- audit logging & replay  
- approval gates  
- data access policies  
- versioning (prompts/workflows)  
> Regulated industries require this.

**Layer 5 — Observability + operations**
- monitoring and alerting  
- failure handling / compensation patterns  
- performance tracking  
- change management  
> Production maturity lives here.

**Positioning line:**  
> AI coding accelerates building blocks.  
> OutSystems enables enterprise execution.
